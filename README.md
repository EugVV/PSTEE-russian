PSTEE-russian
=============

Русский перевод Planescape: Torment Enhanced Edition (Si1ver)
-------------------------------------------------------------
На основе перевода из Arcane Pack.

Компонент «Russian translation of menu buttons» мода заменяет официальные рендеры кнопок и иконок характеристиков на нарисованные Apxu (можно не устанавливать, если официальные нравятся больше, шрифт и тут и там использовался одинаковый, надписи тоже идентичны).

Версия перевода: 2.1.

Версия игры: 3.2.2.0.

Состояние перевода
------------------
Переведено всё.

Установка перевода
------------------
Сборка перевода разбита на три части, каждая из которых может быть установлена независимо от других:

Перевод текста (включает субтитры катсцен и отдельные имена для типовых женских персонажей) на [yandex](https://disk.yandex.com/d/IeGK-_T4FIfUZQ), файл обновляется.

Шрифты для перевода на основе оригинальных шрифтов игры (если хочется заменить поставляемый с игрой PT Serif) на [yandex](https://disk.yandex.com/d/E0pTIlK-3Jwhng).

Перевод графики кнопок меню и иконок характеристик авторства Apxu (если по каким-либо причинам не устраивает поставляемая с официальным переводом) на [yandex](https://disk.yandex.com/d/ZVccFMkcGhxzUg).

Все части устанавливаются простой распаковкой архивов со ссылок выше в каталог с игрой.

Сборки для старых версий 
------------------------
Сборка перевода 2.0 для 3.1.4 (и более ранних) на [yandex](https://yadi.sk/d/gbht6Qxg3H2fXT).

Просто распаковываем собранный перевод в каталог с игрой.

Сборка перевода 2.0 для 3.1.4 под Android: [yandex](https://yadi.sk/d/2CjQ-AiOIRX_vQ).
Для установки копируем zip-файл как есть в каталог `<Внутренняя карта>/Android/data/com.beamdog.pstee/files`. Запускаем игру, выбираем язык (Alter Senses – Language). Из-за особенностей загрузки движком расширений в zip выбирать язык придётся после каждого запуска игры.
В Android 11 доступ к каталогам в Android/data есть только у приложений-владельцев соответствующих каталогов, но файл всё ещё может быть скопирован по USB.
